# Code Availability

All code used for genome-resolved functional integration, compositional
ecological modeling, machine learning analysis, and synthetic ecological
perturbation is available in this repository.

The workflow includes:

-   ARG and VF functional harmonization from genome-resolved
    annotations\
-   CLR transformation and batch correction procedures\
-   Diversity and differential mechanism analyses\
-   Functional integration metric computation\
-   Nested cross-validated machine learning models\
-   Synthetic donor--recipient blending simulations for dominance and
    resilience assessment

The code is provided to enable full reproducibility of the analyses
described in the manuscript.\
All scripts use fixed random seeds where applicable, and model
evaluation procedures prevent information leakage between training and
holdout data.
